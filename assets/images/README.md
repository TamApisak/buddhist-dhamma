# รูปภาพของเว็บไซต์

วางรูปภาพจริงของชมรมไว้ในโฟลเดอร์นี้ (ใช้เฉพาะภาพที่ชมรมถ่ายเองหรือได้รับอนุญาตแล้ว)

```
assets/images/
├── logo.png            โลโก้ชมรม 512×512 px พื้นหลังโปร่ง (หรือ logo.svg)
├── about-cover.jpg     ภาพในหน้าเกี่ยวกับชมรม 1200×900 px
├── articles/           ภาพประกอบบทความ 1200×750 px
├── activities/         ภาพกิจกรรม 1200×750 px
└── teachers/           ภาพครูบาอาจารย์ 800×1000 px
```

ตั้งชื่อไฟล์เป็นภาษาอังกฤษตัวพิมพ์เล็ก ไม่มีช่องว่าง เช่น `volunteer-2569-09.jpg`
แนะนำให้ย่อขนาดไฟล์ให้ไม่เกิน 300 KB ต่อภาพ เพื่อให้โหลดเร็วบนโทรศัพท์

วิธีระบุรูปในเนื้อหา: ใส่ที่อยู่ไฟล์ในช่อง `image` ของรายการนั้น เช่น
`image: "assets/images/activities/volunteer-2569-09.jpg"`
และเปลี่ยนโลโก้ที่ `logo` ใน `content/site.js`
